01 — el proceso

Cinco fases. Tú contestas, Claude Code construye.

AgentKit no es una librería ni un SaaS. Es un manual de instrucciones que Claude Code lee y ejecuta dentro de tu terminal. Estas son las fases, en orden, y no avanza a la siguiente sin tu OK.

  1. FASE
    01

    Verifica tu entorno

    Chequea que tengas Python 3.11 o más y Claude Code instalado, arma las carpetas y crea tu .env vacío. Si algo falta, te dice exactamente qué instalar y dónde.

    $ bash start.sh
  2. 02

    Te entrevista sobre tu negocio

    Diez preguntas, una a la vez, en español: cómo se llama tu negocio, a qué se dedica, para qué quieres el agente, qué nombre y qué tono le das, tu horario, tus archivos, tus API keys. Si tienes un PDF con el menú o la lista de precios, lo tiras en /knowledge y lo lee.

    NombreRubroCaso de uso TonoHorarioArchivos
  3. 03

    Genera el agente completo

    Escribe el proyecto entero, comentado en español, con un system prompt hecho a medida de tu negocio. No es un template con huecos: cada archivo sale distinto según lo que contestaste.

    agent/main.py — servidor FastAPI + webhook
    agent/brain.py — Claude API + system prompt
    agent/memory.py — historial por número
    agent/tools.py — herramientas de tu rubro
    agent/providers/ — conexión con WhatsApp
    config/prompts.yaml — la personalidad
    Dockerfile — listo para producción
  4. 04

    Lo pruebas en tu terminal

    Antes de tocar WhatsApp, hablas con tu agente en un chat simulado. Escribes como si fueras un cliente. Si contesta algo que no te gusta, se lo dices a Claude Code y lo ajusta ahí mismo.

    $ python tests/test_local.py
  5. 05

    Deploy a Railway

    Subes el proyecto a GitHub, Railway lo levanta solo, cargas las variables de entorno y conectas el webhook de tu proveedor. Desde ese momento, quien te escriba por WhatsApp habla con tu agente, aunque tu compu esté apagada.

02 — conexión con whatsapp

Dos caminos para conectar tu número.

Tu agente necesita hablar con WhatsApp. Claude Code te pregunta cuál quieres y genera solo el adaptador de ese proveedor, con sus variables de entorno. Puedes cambiar después sin tocar el resto del código.

Recomendado opción A

Zernio

Integración directa sobre la WhatsApp Cloud API de Meta, con el Embedded Signup ya resuelto: conectas tu cuenta de WhatsApp Business desde un botón. Sin crear una app de Facebook y sin pasar App Review. Trae inbox unificado y webhooks firmados.

Dificultad Baja. Se conecta en minutos.
Costo Las primeras 2 cuentas conectadas son gratis para siempre. Sin tarjeta.
Para quién Para casi todos. Si quieres tu agente andando hoy, es por acá.
Sin número Tiene sandbox con número compartido para probar antes de tener el tuyo: 50 mensajes cada 24 horas, gratis, y la sesión te dura 7 días.
WHATSAPP_PROVIDER=zernio
ZERNIO_API_KEY=...
ZERNIO_WEBHOOK_SECRET=...
ZERNIO_ACCOUNT_ID=... (opcional)
Ir a zernio.com
Avanzado opción B

Meta Cloud API directo

La API oficial de WhatsApp, sin nada en el medio. Tú creas la app en developers.facebook.com, le agregas el producto WhatsApp, generas el token permanente y verificas tu cuenta de Facebook Business.

Dificultad Alta. App de Facebook, tokens, verificación de Business.
Costo Le pagas las conversaciones a Meta, directo y sin intermediario.
Para quién Si ya tienes app y Business verificado, o si quieres controlar cada pieza tú mismo.
Sin número Meta da un número de prueba, pero igual necesitas la app creada.
WHATSAPP_PROVIDER=meta
META_ACCESS_TOKEN=...
META_PHONE_NUMBER_ID=...
META_VERIFY_TOKEN=...
META_APP_SECRET=...
META_API_VERSION=v25.0

03 — para qué sirve

El mismo motor, distinto oficio.

Lo que cambia entre un agente y otro no es el código: es el prompt, las herramientas y los archivos que le diste. Estos son los rubros donde más se usa.

01

Restaurante

Toma pedidos, lee el menú del PDF que subiste, arma el carrito, confirma dirección y horario de entrega.

"Dos tacos al pastor y una limonada, para llevar"

02

Clínica o salón

Toma la cita: pregunta el servicio, ofrece los horarios que le pasaste y te deja los datos listos en el historial.

"¿Tienes lugar el jueves por la tarde?"

03

Inmobiliaria

Califica leads: pregunta zona, presupuesto y cuándo se quiere mudar. Los tibios los cuida, los buenos te los pasa al vendedor.

"Busco depa de 2 habitaciones, hasta 900 dólares"

04

Tienda online

Contesta por stock, tallas, medios de pago, costo de envío y estado del pedido. A las 3 de la mañana también.

"¿Les queda la chaqueta negra en M?"

05

SaaS y soporte

Primera línea de soporte: resuelve lo repetido, abre ticket cuando hace falta y escala a un humano lo que no sabe, sin inventar.

"No me llega el mail de verificación"

06

Cualquier otro negocio

Si tienes preguntas que contestas veinte veces por día, el agente las contesta por ti con tu información, tu tono y tu horario. Nada más.

"¿Hasta qué hora abren hoy?"

04 — quién y por qué

Este repo casi no tiene código.

Lo que hay adentro
CLAUDE.md — el cerebro
/build-agent — el disparador
start.sh — el arranque
scripts/audit.py — la auditoría
README.md — el mapa
LICENSE — MIT

Cada vez que alguien me preguntaba cómo poner un bot de WhatsApp en su negocio, la respuesta honesta era fea: o contratas a un dev, o pagas ochenta dólares por mes por algo que contesta con botones.

Así que en vez de escribir otro bot, escribí las instrucciones para que Claude Code escriba el tuyo. Todo el trabajo está en un archivo, CLAUDE.md: qué preguntar, en qué orden, qué generar con cada respuesta, cómo probarlo y cómo subirlo. Tú clonas, corres un comando y contestas. El código aparece.

Lo importante: el agente que sale es tuyo. Vive en tu máquina, en tu repo, con tus API keys. Puedes leerlo, romperlo, cambiarle el prompt a las tres de la mañana. No hay plataforma en el medio, no hay suscripción, no hay nada que se apague si yo desaparezco. Licencia MIT, haz lo que quieras.

Lo hice yo, Enrique. Subo cosas de IA bajo el nombre Todo de IA, y este repo salió de ahí. Si construyes algo con esto, mándamelo: me da mucha curiosidad ver qué sale.
